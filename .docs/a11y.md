# 可近用性（a11y）規範

- 使用語義化標籤與正確 ARIA 屬性；互動元素需可透過鍵盤操作（Enter/Space）。
- 焦點管理：開啟對話框、抽屜、Popover 時正確聚焦；關閉時回到觸發元素。
- 對比度：遵循 WCAG AA；文字可縮放不破版。
- 圖片/媒體：提供 `alt`、caption 或 aria 描述；非裝飾性 SVG 加 `role="img"` 與 `aria-label`。
- 表單：關聯 `label` 與 `id`，提供錯誤訊息 `aria-describedby`。
- 動畫：避免造成暈眩，尊重 `prefers-reduced-motion`。

## 焦點與 aria-live

- 對話框開啟時將焦點移入內容，關閉時返回觸發器。
- 重要狀態變更（提交成功/失敗）以 `aria-live="polite"` 公告。

```tsx
<div role="status" aria-live="polite" className="sr-only" id="form-status" />
```

## 鍵盤操作

- 可點擊元素需使用原生 `button` 或設定 `role="button" tabIndex={0}` 並處理 Enter/Space。

```tsx
const handleKeyDown = (e: React.KeyboardEvent) => {
  if (e.key === 'Enter' || e.key === ' ') {
    e.preventDefault()
    onActivate?.()
  }
}
```
