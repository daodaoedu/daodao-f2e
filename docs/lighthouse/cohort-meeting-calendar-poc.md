## 原型範圍

會員進入已加入的 `/cohorts/{cohortId}`，點設定旁的小日曆，開啟聚會資訊 popup。取代會員頁原本佔用空間的完整時程列表；公開活動、加入頁維持原有呈現。沒有獨立 POC 頁。

- 日期 `YYYY/MM/DD`、24 小時制；下一場日期與時間同列。
- 分組為下一場聚會、接下來、進行中、已結束；保留過去聚會並支援長清單捲動。
- 顯示 Lighthouse 基本資訊的地點、線上連結、日期、起訖時間、時區；線上連結開新分頁。
- 小 X、白色圓形關閉按鈕；沒有日曆 tooltip，保留「聚會時間」無障礙名稱。支援 Escape 關閉與焦點回到日曆。
- 首頁「今天想從哪裡開始？」所在區域顯示已加入、published、開始日已到的各場次捷徑，不合併各場次日曆。沒有新增結束日自動移除規則。

## 時區與資料

沿用 dev 的 `formatSessionForTimezone`，包含跨日顯示及夏令時間規則。會員資料目前沒有帳戶時區欄位，本 POC 採瀏覽器／裝置時區，無法取得則顯示並標示場次時區；未新增會員時區欄位或設定介面。

會員列表與詳情使用原有 API 與權限。Lighthouse 維護完整聚會資料。本次不提交本機資料庫、登入捷徑、token、固定會員 ID 或對正式資料的寫入。

## 重現本機示範

使用已加入測試場次的一般會員，Lighthouse 基本資訊可設定 Asia/Taipei、地點「台北市中正區・共享空間」、一個可用的線上聚會連結。原型示範資料為 2026/10/29、11/12、11/19、11/26、12/03，19:00–21:00；分組依實際現在時間更新。示範資料需由環境建立，程式不注入假場次。

執行 `pnpm install --frozen-lockfile`、依專案設定環境與後端後，執行 `pnpm dev:product`。會員首頁點場次捷徑，再點日曆；檢查桌面與窄螢幕、已結束場次、Escape／X 關閉、裝置時區切換及跨日顯示。這是 POC 交接，不能代替部署後完整 FRD 驗收。
