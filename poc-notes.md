# Cohort setup and activity preview POC

## How to open

Open `/zh-TW/lighthouse/programs`, create or edit a cohort, and select **預覽活動課程探索頁** in the setup footer. The preview uses the current form values, including unsaved drafts.

## What this demonstrates

- A wider, read-only activity page preview with the Explore page's information order, icons, session schedule, program details, host, and organization.
- Meeting links accept a scheme-less `meet.google.com/...` value and save it with `https://`.
- Cohort description allows up to 100 characters; signup method sits beside fee selection.
- Privacy copy reflects the public visibility behavior. Check-in privacy and coach-comment privacy switches are disabled while those features are unavailable.

The preview does not publish a cohort or allow joining. It is an implementation reference and has not been validated as production behavior.
