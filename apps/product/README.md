# @daodao/product

DaoDao 產品網站應用程式。

## 開發

```bash
# 開發模式
pnpm dev

# 構建
pnpm build

# 啟動生產環境
pnpm start
```

## 結構

- `src/app/` - Next.js App Router 頁面
- `src/app/[locale]/` - 多語系路由
- `public/` - 靜態資源

## 依賴

- `@daodao/i18n` - 多語系支援
- `@daodao/ui` - UI 組件庫
- `@daodao/shared` - 共享工具
- `@daodao/api` - API 客戶端
- `@daodao/features-quiz` - Quiz 功能模組

## 功能

產品網站目前處於開發階段，將包含以下功能：

- 使用者認證與授權
- 專案管理
- 資源管理
- 練習功能
- 學習馬拉松
- 想法分享
- 社群圈圈
- 其他產品核心功能
